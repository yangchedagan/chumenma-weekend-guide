# 前端视觉与交互参考

调研日期：2026-09-15。目标：让「出门吗」拥有更明确的艺术感与现代感，同时保持活动筛选和出行规划易用。

本次为参考调研与改版建议，尚未实施视觉改版。下文的适配方式是针对本产品的设计判断，不是上游项目自带的业务功能。

## 当前版本需要解决的问题

1. 大部分内容都被包装成相似尺寸的圆角卡片，内容主次和浏览节奏不够明显。
2. 少量照片在不同活动间重复使用，容易削弱城市和活动的具体感。
3. “小美好”“给自己充电”等文案出现较多，日期、地点、费用等决策信息可以更突出。
4. 浅绿、黄色、圆角、标签、图标同时承担装饰，缺少一个足够清晰的视觉重点。

## 推荐改版方向：城市文化刊物

### 构图

- 用一条紧凑筛选栏保留城市、天气、预算、人数；打开页面即可开始选择活动。
- 推荐区域采用有主次的图片编排：重点路线占较大画幅，普通活动使用较小图块或文字列表。
- 保留明确的对齐关系，用细线和间距建立分区，减少卡片外框与阴影。
- 出行单保持容易发现，可作为桌面右侧的轻量侧栏和移动端的底部入口。

### 字体与颜色

- 中文标题可尝试有出版物气质的宋体，正文和控件使用清晰黑体；日期、预算、路线编号采用统一数字样式。
- 以黑白为主，选择一种明确的点缀色，例如朱红；颜色集中用于选中状态、行动按钮与少数章节标记。
- 中文为主要内容语言，英文仅在有实际信息价值时保留。

### 内容

- 展览、演出、街区漫游与徒步使用能区分类别和城市的配图，图片来源与示意属性继续保留。
- 卡片优先显示“活动名 / 区域 / 日期 / 人均费用”，推荐理由压缩为一句有依据的信息。
- 文案更具体，例如“周六 · 西岸 · 免费”，减少重复情绪口号。

### 动效

- 类别切换：短暂淡入与轻微位移，避免整屏重新闪现。
- 列表到详情：由所选图片扩展到详情主图，返回恢复浏览位置。
- 加入出行单：按钮状态和清单数量联动反馈。
- 动效参考时长 180–350ms；手机端以点击为主，核心操作不得依赖悬停；尊重减少动态效果设置。
